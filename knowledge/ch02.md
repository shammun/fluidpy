## 1. What clicked — the teaching spine (our words, with equation numbers)
1. **C01 Summation convention (§2.1, (2.2), (2.9)–(2.11), (2.16)–(2.17)).** A letter that appears twice in a term is a
   sum over 1, 2, 3; a letter that appears once is free and names the components of the answer. `expand_indices`
   writes the hidden sums back out, and `np.einsum` is the same rule in code.
2. **C02 Direction cosines C_ij = e_i·e'_j (§2.2).** Row = old axis, column = new axis, so the columns of C are the new
   unit vectors in old components. Orthogonality CCᵀ = CᵀC = I and det C = +1 follow from completeness (D02, the
   book's Exercise 2.8), and the inverse (2.7) follows from that (D03).
3. **C03 Transformation of components x'_j = x_i C_ij (2.5), and what a vector is (2.8).** Project the same arrow onto
   the new axes (D01). "Vector" means "transforms like this". A triple that does not (x², (|x|, 0, 0)) fails the test
   by order one, not by round-off. Ex. 2.1's polar components are (2.5) with j ∈ {r, θ}.
4. **C04 Stress tensor τ_ij (§2.4).** First index = the face's normal, second index = the direction of the force. On
   the +e_i face positive components point along +e_j. Opposite faces carry opposite tractions (R01, Newton III).
5. **C05 Cauchy's traction f_i = τ_ji n_j (2.15).** Shrink a tetrahedron: face terms scale as h², volume terms as h³,
   so only the stresses survive (D05). **The contraction is on the FIRST index** (f = n·τ). This equals τ·n only for
   symmetric τ, which Ch. 4 proves.
6. **C06 Tensor transformation τ'_mn = C_im C_jn τ_ij (2.12).** Write (2.15) in two frames with f and n both vectors,
   and (2.12) is forced: one C per index (D06). We teach (2.15) before (2.12), the reverse of the book's order, and the
   notebook says so. A fixed array that does not obey (2.12) is a matrix, not a tensor.
7. **C07 Contraction and invariants (§2.5, (2.14)).** A contracted index pair is "C times Cᵀ = δ", so every fully
   contracted quantity ignores the frame: I₁ = A_ii, I₂ = ½(I₁² − A_ij A_ji), I₃ = det A (D18). These are the
   coefficients of λ³ − I₁λ² + I₂λ − I₃ (Vieta). The book's A:B = A_ij B_ji is not the Frobenius A_ij B_ij.
8. **C08 Alternating tensor ε_ijk (2.18)–(2.21).** Cyclic +1, anticyclic −1, repeated 0. It turns cross products and
   curls into index sums, and the epsilon–delta identity (2.19) closes them (D09, the one tool the book never proves).
9. **C09 Gradient ∇φ (2.22).** It is perpendicular to the level sets, its length is the steepest slope, and
   ∂φ/∂n = ∇φ·n. This block also introduces the project grid ([k, j, i] = (z, y, x)) and explicit second-order stencils.
10. **C10 Divergence ∇·u = ∂u_i/∂x_i (2.23).** The sum of the stretching rates along the axes; "solenoidal" means zero.
    The velocity gradient G[i, j] = ∂u_i/∂x_j; the tensor divergence contracts the SECOND index. Ex. 2.3: ∇·(a x) = 3a.
11. **C11 Curl (∇×u)_i = ε_ijk ∂u_k/∂x_j (2.24)–(2.25).** Components by ε enumeration (D12). For solid-body rotation,
    ∇×(b × x) = 2b, and a paddle wheel turns at half the curl.
12. **C12 Symmetric + antisymmetric split (§2.10, (2.26)–(2.29)).** B = ½(B + Bᵀ) + ½(B − Bᵀ) is unique and does not
    depend on the frame (D14). An antisymmetric tensor is a hidden vector: R_ij = −ε_ijk ω_k, and R·x = ω × x (D15). A
    symmetric tensor cannot see the antisymmetric part (τ_ij A_ij = 0). **The book's R = G − Gᵀ carries ω = ∇×u; the
    antisymmetric part A = ½R carries ½∇×u (the spin rate).**
13. **C13 Principal axes (§2.11).** A real symmetric τ has real eigenvalues and perpendicular eigenvectors. Rotating to
    those eigenvectors makes τ diagonal, and λ_min ≤ n·τ·n ≤ λ_max with maximum shear (λ_max − λ_min)/2 (D17 ★★★,
    with a sympy check). Ex. 2.4 gives λ = ±Γ on the 45° axes.
14. **C14 Gauss' theorem (2.30).** On a box, the fundamental theorem of calculus along one axis turns a derivative
    inside into the field on two faces (D25). Tiles share faces with opposite normals, so the interior faces cancel and
    the result holds for any volume. Divergence theorem = the vector case; sphere benchmark 8π/3.
15. **C15 Integral definitions (2.31)–(2.33).** Apply (2.30) to a shrinking box and divide by V (D21): the divergence
    is the outflux per unit volume. Ex. 2.5 recovers the Cartesian (2.23) face by face (D22). The limit is approached
    at second order in h, which the notebook measures.
16. **C16 Stokes' theorem (2.34)–(2.35).** One small rectangle's circulation equals its curl times its area. Tile the
    surface: shared edges are walked twice in opposite directions and cancel (D26). The normal curl is circulation
    per unit area. For an irrotational vortex, Stokes fails when the loop encloses the singular core, and the code
    reports this instead of asserting.

## 4. Mathematics → Python lessons (new pitfalls)
- **A test that asserts f(B) == g(B) between two of our own functions is not evidence for the book's convention.**
  `rotation_tensor` returned A = ½(G − Gᵀ) and the first-round test asserted it equals `antisymmetric_part`, so the
  test passed and the factor 2 went unnoticed (review M1). Pin every convention to a field with a known answer from the
  book: vector(`rotation_tensor`(∇(b × x))) = 2b = ∇×u.
- **Preset names are physics.** "uniaxial_extension" was diag(Γ, −Γ) (divergence-free) and the test enshrined the
  matrix (review M2). Test a preset by its defining property (trace Γ, spin content, area growth e^{Γt}), not by its
  matrix.
- **sympy symbols with assumptions are different symbols.** `ch02.coordinates(3)` makes `Symbol('x1', real=True)`;
  `sp.symbols('x1')` is a different object, so every derivative came out 0 and the notebook printed `(0, [0,0,0])`
  under a comment claiming 3a (lesson Must 1). Build expressions from the library's own `coordinates`, and assert the
  symbolic twin against the numeric result in the same cell.
- **Discrimination proofs for conventions**: 8 wrong variants were patched in (τ_ij n_j, active C x, +ε for R,
  swapped double dots, transposed G, first-index tensor divergence, clockwise loops, `np.gradient` edges). Each was
  caught by at least one test. Do this for every convention a chapter pins.
- **`np.gradient` is first order at the edges**: patched into the operators, it failed 4 of 5 order tests. The
  project stencils are explicit second-order one-sided at the edges (orders 1.97–2.03).
- **Discrete ∇×∇φ = 0 and ∇·(∇×u) = 0 hold to round-off** (< 1e-11), not "to truncation order", because difference
  stencils along different axes commute exactly (O6).
- **A_ij A_ij is also frame-independent** (= tr(AAᵀ)); what fails is using it as the λ-coefficient of the
  characteristic polynomial. I₂ needs the closed chain A_ij A_ji (O3; the first design text had this wrong).
- **sympy 1.14 `.norm()` introduces `Abs(...)`** and `simplify` then fails to reach 0: normalise with
  `b / sp.sqrt(b.dot(b))` in symbolic eigenvector checks (O4).
- **A theorem with hypotheses reports, it does not assert**: `stokes_theorem_check` returns `hypothesis_ok=False` and a
  note when the field's `singular_at` lies inside the loop (irrotational vortex: Γ = 2πK vs curl flux 0).
- **Two index orders for "the gradient of a vector"**: `vector_gradient` G[i, j] = ∂u_i/∂x_j (Ch. 3 convention) vs
  `integral_gradient`/`gauss_gradient_box` [i, j] = ∂Q_j/∂x_i (the natural order of (2.31)). They are transposes, and
  both docstrings say so.
- **Periodic grids drop the duplicate end node** (`grid(..., periodic=True)`: h = L/n). Using `bc="periodic"` on a
  non-periodic field falsely shows order ≈ −1.
- **`np.transpose(a, axes)` puts old axis `axes[p]` in position p**: `np.transpose(eps, (1, 2, 0))[i, j, k] =
  eps[k, i, j]`. The first primer stated it backwards, and the demo did not catch it because ε is invariant under both
  cyclic shifts. Demo an idiom on an object where the wrong statement fails (`np.arange(27).reshape(3, 3, 3)`).
- **matplotlib 3.11**: `print_figure` re-installs constrained layout after the first saved frame, so an animation that
  uses `subplots_adjust`/`fig.text` must set `plt.rcParams["figure.constrained_layout.use"] = False` for the save and
  restore it afterwards (`notebooks/build_ch02.py` l. 3482/3507).
- **`tools/shot.py` `py:` parity expressions run with no builtins**: index dicts/tuples down to one float
  (`ch02.traction_2d([[0,1],[1,0]], 0.5236)["sigma_n"]`, `ch02.principal_axes(...)[0][1]`); no `abs`, `len`, `float`.
- Book typos taught as corrected and recorded: Ex. 2.4's Γ is the element S₁₂ (the book's "2S₁₂ = Γ" line is
  inconsistent with its matrix); Ex. 2.3's third term is a x₃ e₃; Ex. 2.6's second bracket uses u_y; the lower limit
  in (2.27) is i = 1; Fig. 2.10's n_c points into A (the analysis text said "outward"); orthogonality is Exercise 2.8,
  not Eq. (2.6).

## 5. Conventions used (new in ch02; see `knowledge/notation.md`)
- Pure mathematics, dimensional where physical: stress in Pa, strain and rotation rates in 1/s, lengths in m, angles
  in radians. No non-dimensional scales.
- **Direction cosines C_ij = e_i·e'_j, passive**: x' = Cᵀx (2.5), x = Cx' (2.7), τ' = CᵀτC (2.12). For axes turned by
  +θ, `rotation_matrix_2d(θ)` equals Wikipedia/scipy's active R(θ) and is applied as Rᵀ. The explainer's "active"
  toggle is labelled "Wikipedia R".
- **Traction contracts the first index**: f_i = τ_ji n_j = (n·τ)_i. **Tensor divergence contracts the second**:
  (∇·τ)_i = ∂τ_ij/∂x_j (`index=1` default). They agree only for symmetric τ.
- **Double dot**: book A:B = A_ij B_ji (= tr(AB)); Frobenius A_ij B_ij (= tr(ABᵀ)). Always pass `convention=`.
- **Velocity gradient** G[i, j] = ∂u_i/∂x_j; S = ½(G + Gᵀ).
- **Rotation**: the book's R = G − Gᵀ (`rotation_tensor`) with vector ω = ∇×u (vorticity); the antisymmetric part
  A = ½R (`antisymmetric_part`) with vector ½∇×u (spin rate). G = S + ½R = S + A. **Never call the vector of A "ω".**
  R_ij = −ε_ijk ω_k, ω_k = −½ ε_ijk R_ij, R·x = ω × x.
- **Stress sign**: tensile positive; on the +e_i face positive components point along +e_j; pressure τ = −pδ.
- **Stokes orientation**: n_c is the in-surface normal to C pointing **into** A; t = n_c × n runs counterclockwise
  seen from the tip of n; (n_c, n, t) is right-handed. Closed surfaces use the outward n.
- **Grid layout (project-wide)**: 3-D arrays `[k, j, i]` = (z, y, x), x on the last axis
  (`np.meshgrid(z, y, x, indexing="ij")`); 2-D `[j, i]` (`indexing="xy"`); vector components on axis 0
  (`u[c, k, j, i]`); direction d ∈ {0, 1, 2} = (x, y, z) lives on array axis ndim − 1 − d; `Grid.h` and gradient
  components are ordered **(x, y, z)**; values at nodes (h = (b − a)/(n − 1); periodic h = L/n).
- **Gradient of a vector, two orders**: `vector_gradient` [i, j] = ∂u_i/∂x_j vs `integral_gradient` /
  `gauss_gradient_box` [i, j] = ∂Q_j/∂x_i (transpose).
- **Eigen output order**: `principal_axes` λ ascending, B columns unit eigenvectors, det B = +1; `example_2_4` keeps
  the book's order (Γ, −Γ).
- **Superscript k on λ^k, b^k is a label**, not a power.
- **Face keys**: `cube_face_tractions` `"+1" … "-3"`; `flux_through_faces` `"+x" "-x" "+y" "-y"`;
  `flux_through_box_faces` uses the book's Fig. 2.4 letters (EADH = +x₁ … DCGH = −x₃).
- Changes vs ch01: `traction_components` moved from `ch01_introduction` to `core.tensors` (re-exported, ch01's 107 tests
  unchanged). Symbols reused with new meanings: Γ, θ, φ, τ, n, h, R, A, G, K, m, s, t, λ, a, b (flagged in notation.md).
