## 1. What clicked — the teaching spine (our words, with equation numbers)
One recipe, used seven times: **basic state + small disturbance → linearise → normal modes → an eigenvalue problem for the
growth rate → the neutral curve → its minimum is the critical number.** Every section changes only the physics that feeds the
recipe (gravity vs shear at an interface, buoyancy vs two diffusions, centrifugal force vs viscosity, shear vs stratification,
shear vs viscosity), and the chapter ends where the recipe stops working: nonlinear saturation, transition and chaos.
1. **C01 Normal modes and the vocabulary.** $u=\hat u(z)\,e^{ikx+imy+\sigma t}=\hat u(z)\,e^{i|\mathbf K|(\mathbf e_K\cdot\mathbf
   x-ct)}$ (11.1), so $\sigma=-\mathrm i|\mathbf K|c$: σ_r = |K|c_i (growth), σ_i = −|K|c_r (D01). Stable means σ_r ≤ 0 **for
   every k**; marginal state σ_r = 0, stationary (σ_i = 0, "exchange of stabilities") or oscillatory (overstability). Logic
   primed once (P255: necessary vs sufficient, contradiction) and reused by name in every theorem.
2. **C02 Kelvin–Helmholtz.** Linearised kinematic (11.9) and dynamic (11.13) conditions (D02) + decaying modes give
   $c=\frac{\rho_2U_2+\rho_1U_1}{\rho_2+\rho_1}\pm\Big[\frac gk\frac{\rho_2-\rho_1}{\rho_2+\rho_1}-\rho_1\rho_2\Big(\frac{U_1-U_2}
   {\rho_1+\rho_2}\Big)^2\Big]^{1/2}$ (11.18) (D03): unstable when $g(\rho_2^2-\rho_1^2)<k\rho_1\rho_2(U_1-U_2)^2$ — short waves
   always lose; the vortex sheet (11.20) grows at kΔU/2 for every k. With depth and surface tension (Ex. 11.1, D04): air over
   water needs ΔU_min = 6.70 m/s at λ = 1.73 cm; unstable band [149.15, 887.44] m⁻¹ at 8 m/s; Rayleigh–Taylor cut-off 1.727 cm.
   Mixing a sheet into a linear layer leaves E_f/E_i = 2/3.
3. **C03 The Bénard amplitude problem.** Conduction + perturbation (D05), pressure eliminated (11.29) (D06), scaled normal
   modes (11.34)–(11.38) (D07) with $\mathrm{Ra}=g\alpha\Gamma d^4/(\kappa\nu)$ (11.21); σ computed by Chebyshev collocation
   (`benard_growth_rate`); **σ is real for Ra > 0** (D08, Ex. 11.6), so onset is σ = 0. Γ here is −dT̄/dz (slip S10) — three
   conventions tabulated.
4. **C04 Rigid–rigid neutral curve.** σ = 0 gives one sixth-order equation (11.40) (D09); roots (11.42), even solution, a 3 × 3
   determinant that is purely imaginary (D10 ★★★; slip #1 corrected): **Ra_c = 1707.7618 at K_c = 3.1163** (Chandrasekhar 1707.762
   / 3.117), rigid–free 1100.6496 / 2.68234, odd mode 17610.394 / 5.36465. Two routes (determinant = Chebyshev to ≤ 1e-9).
5. **C05 Free–free closed form.** $\mathrm{Ra}=(\pi^2+K^2)^3/K^2$ (11.44), K_c² = π²/2, Ra_c = 27π⁴/4 = 657.511 (D11; slips #2,
   #3); growth-rate quadratic $(\sigma+a^2)(\sigma/\Pr+a^2)a^2=\mathrm{Ra}K^2$, a² = π² + K² (D12, ours) — reused by C06 and C15.
6. **C06 Salt fingers.** The marginal problem is free–free Bénard with Ra → Rs − Ra (D13):
   $\frac{gd^4}{\nu}\Big[\frac{\beta}{\kappa_s}\frac{dS}{dz}-\frac{\alpha}{\kappa}\frac{d\bar T}{dz}\Big]=\frac{27}{4}\pi^4$
   (11.46). A bottom-heavy column overturns because heat leaks 100 × faster than salt; (11.46) marks σ = 0 only — the diffusive
   regime is oscillatory (cubic `double_diffusive_sigma`), and **a top-heavy layer below 27π⁴/4 is stable** (review M1).
7. **C07 Taylor–Couette.** Ring interchange ΔE ∝ (Γ₂² − Γ₁²): unstable if Γ² falls outward (Rayleigh); narrow-gap system
   (11.51) (D14 ★★★, slip #12) with $\mathrm{Ta}=-4A\Omega_1d^4/\nu^2$ (11.52); μ → 1 maps onto Bénard (D15), Ta_c(μ = 0) =
   3389.900 at k = 3.12660; the fit (11.54) is +0.77 % at μ = 0 and worse for counter-rotation.
8. **C08 Taylor–Goldstein.** $(U-c)\big(\hat\psi''-k^2\hat\psi\big)-U''\hat\psi+\frac{N^2}{U-c}\hat\psi=0$ (11.61) (D16, D17;
   slip #4); N² = 0 is Rayleigh's equation; tanh layer neutral curve J = k(1 − k).
9. **C09 Miles–Howard.** φ = ψ̂/(U − c)^{1/2}, multiply by φ*, integrate, imaginary part (D18 ★★★): **Ri ≡ N²/(dU/dz)² > ¼
   everywhere ⇒ stable** (11.66)–(11.67) — a guarantee, not a trigger (R = 3, J = 0.4 counter-example grows with Ri_centre 0.4).
10. **C10 Howard's semicircle.** $\int[U^2-c_r^2-c_i^2]Q\,dz>0$ (11.72) ⇒ c in the half-disc on [U_min, U_max], kc_i ≤
    k(U_max − U_min)/2 (D19 ★★★; slips #8, #11; the semicircle inequality itself is unnumbered, p. 507).
11. **C11 Squire + Orr–Sommerfeld.** (11.78) maps a 3-D mode to a 2-D one at lower Re; $(U-c)(\phi''-k^2\phi)-U''\phi=
    \frac{1}{\mathrm ikRe}(\phi''''-2k^2\phi''+k^4\phi)$ (11.79) with φ = φ′ = 0 (11.80) (D20, D21). Orszag's
    c = 0.23752649 + 0.00373967i reproduced to 1e-9.
12. **C12 Rayleigh / Fjørtoft.** $c_i\int U''|\phi|^2/|U-c|^2\,dy=0$ (11.84) ⇒ U″ must change sign (D22); Fjørtoft
    U″(U − U_I) < 0 somewhere (11.86); both necessary only (sin y with 2b < π satisfies both, nothing grows); critical layer and
    cat's eyes.
13. **C13 Viscous results.** Plane Poiseuille **Re_c = 5772.2218 at k_c = 1.020545** (Orszag 5772.22); band at Re = 10⁴
    k = 0.797–1.095; Blasius Re_c(δ*) = **519.0601** at k_c = 0.30377 (Thomas 519.2); Bickley jet 4.0170 at k = 0.1728 with a
    **two-band picture** (one band to Re ≈ 17.5, then a stable gap between a long-wave band and the main band); tanh layer
    Re_c = 0; Couette stable.
14. **C14 Energy equation.** dE/dt = −∫⟨uv⟩U′ dy − Λ (11.88) (D23): viscosity shifts the u–v phase so the Reynolds stress
    extracts energy; P/Λ = 1.6163 at Re = 10⁴, budget closes to 4.5e-12. The same −⟨uv⟩U′ is Ch. 12's production.
15. **C15 Lorenz.** Three-mode truncation (11.90) → $\dot X=\Pr(Y-X),\ \dot Y=-XZ+rX-Y,\ \dot Z=XY-bZ$ (11.91) (D24 ★★★),
    b = 8/3 at k² = π²/2; pitchfork at r = 1, Hopf at r_H = Pr(Pr + b + 3)/(Pr − b − 1) = 24.7368 (D25); separation slope
    ≈ 0.9, predictability 29.14 time units from δ₀ = 1e-8; logistic period doubling δ₈ = 4.669191.

## 4. Mathematics → Python lessons (new pitfalls only; each a rule, with the measured evidence)
- **(a) A fixed truncation box for an unbounded profile is a different problem at long wavelength.** A mode decays like
  e^{−k|y|}; a box of 30 holds 1.5 e-folds at k = 0.05. Rule: **box = max(profile box, 12/k)** (`decay_box`, `os_box_numerics`)
  and prove it by **box AND N doubling** plus one route with no box. Evidence: TG at k = 0.05 — +26 % at J = 0.04, +86 % at
  0.045 and *spurious growth* 0.0078 at J = 0.05 (above the neutral curve); Bickley lower neutral branch at Re = 7.2
  0.0676 → 0.0211 (the whole lower branch was a box artefact; true picture: two bands and a gap); Bickley Re = 14.58, k = 0.04
  c_i −0.0184 → +0.001255; Blasius Re_c 519.0765 → 519.0601 (box 20 δ* vs converged); Blasius lower branch at Re = 6000
  0.07248 → 0.07902 (+9 %); tanh Re = 1, k = 0.05: 0.161 → 0.28162; Rayleigh rows at k = 0.1 5e-4 off in fixed boxes.
- **(b) A "converged-mode filter" can turn a real mode into a false zero, or hand back a lower mode.** TG tongue: 0 reported in
  a strip 0.0375–0.06 wide under J = k(1 − k) for k ≥ 0.65 (36 unstable grid points); Rayleigh jet at k = 1.8, 1.9: 0 instead
  of c_i = 0.02432, 0.01163; Bénard rigid–free K = 1.84, Ra = 2105.3: −39.61 (the second mode) instead of +7.1195 — the *finer*
  solve was less accurate than the coarse one (N ≥ 60 round-off). Rules: a function **returns the leading mode or raises**,
  never a lower one; **a 0 in a table has a stated meaning** ("kc_i < 0.004 within 0.006 of the curve", in the docstring and the
  CSV header); "no discrete mode found" is a search result, not a proof.
- **(c) Near a neutral point the real-axis Rayleigh problem cannot be resolved by more points** (the critical layer is a
  singularity on the grid). Go round it on a complex path (`rayleigh_eigs_contour`: below the axis where U′ > 0, above where
  U′ < 0; contour = two shooting codes to 1.05e-10 on 56 entries; c_i/(k_n − k) → 0.111, 0.181, 0.637 linearly at exact neutral
  points) and **always keep an independent route**: shooting (Rayleigh, TG), the 6 × 6 / 3 × 3 determinant (Bénard), the
  compound matrix (Orr–Sommerfeld, no box and no collocation), Galerkin (Taylor). Where the nodes sit matters more than how
  many: `decay_map_scale(k)` at N = 100 = N = 240 = shooting to ≤ 1.7e-6. A new solver option needs its own test: the
  contour's `semi_infinite` taper returned "no mode" for c_i up to 0.126 and is now refused.
- **(d) Mode families.** The least-damped mode is not the mode to interpolate (it changes family outside the neutral curve —
  wall mode ↔ centre mode); a neutral curve can consist of several bands carried by different modes (Bickley: gap opens near
  Re ≈ 17.5, `same_mode` = 0 from Re ≈ 19). Track by continuation, record where families exchange, **never join a curve across
  NaN** (NaN = "unstable down to k = 0.02", not "stable"). The leading box eigenvalue at small k can be the continuous spectrum
