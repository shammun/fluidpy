## 1. What clicked — the teaching spine (our words, with equation numbers)
One ruler and three questions. **A difference stencil is a weighted sum of Taylor series; the first term it fails to cancel
is its error, and its power of Δx is the order** (the ruler). Then every scheme is asked: is it *consistent* (the leftover
vanishes as Δx, Δt → 0), is it *stable* (no Fourier mode of the round-off grows: |G| ≤ 1), and — by Lax — together that is
*convergence*. Finite elements reach the same tridiagonal equations by a different road (weak form → hats → element blocks)
and win on geometry. Incompressible flow adds two difficulties: convection-dominated layers thinner than a cell (wiggles vs
numerical diffusion) and the pressure as a constraint (weak compressibility, projection on a staggered grid, mixed elements
that satisfy LBB). The chapter ends on the habit that makes any of it trustworthy: a published benchmark plus grid
convergence at the expected order.
1. **C01 Stencils and order.** Add/subtract the neighbours' Taylor series (10.4)–(10.5): forward/backward
   $[\partial T/\partial x]_i=(T_{i+1}-T_i)/\Delta x+O(\Delta x)$, centred $(T_{i+1}-T_{i-1})/(2\Delta x)+O(\Delta x^2)$ (10.6),
   centred second derivative $(T_{i+1}-2T_i+T_{i-1})/\Delta x^2+O(\Delta x^2)$ (10.7) (D01, 9 steps; the forward error is
   −(Δx/2)T_xx). `fd_weights(offsets, m)` solves the Taylor-matching Vandermonde system in exact rationals (also the one-sided
   (−3/2, 2, −½) of p. 450 and (2, −5, 4, −1) of (10.149)). Measured orders 1.004/0.996/2.000/2.000/1.977; **round-off ε/h
   (ε/h² for second derivatives) makes the total error rise again below h ≈ 1e-5 / 1e-3** (P222) — the log–log error curve
   has a floor.
2. **C02 FTCS (and BTCS).** Replace each derivative of (10.1) by a stencil: $T^{n+1}_i=T^n_i-\alpha(T^n_{i+1}-T^n_{i-1})+
   \beta(T^n_{i+1}-2T^n_i+T^n_{i-1})$ (10.10), α = uΔt/(2Δx), β = DΔt/Δx² (10.11) (D02); **the Courant number is C = 2α**.
   BTCS (10.12)–(10.13) puts the new level on the right: one tridiagonal solve per step (`solve_banded`). u = 0 reproduces
   ch01's FTCS to 1e-14. Neumann by a ghost node T_{N+1} = T_{N−1} + 2Δx q (P223).
3. **C03 Consistency and truncation error.** Put the exact T into the scheme: E = (Δt/2)T_tt + u(Δx²/6)T_xxx −
   D(Δx²/12)T_xxxx + O(Δt², Δx⁴) (10.16)–(10.17) (D03 ★★, 11 steps; **the book never writes the time series**
   T^{n+1} = T + ΔtT_t + ½Δt²T_tt). Measured remainder (measured − (10.17)) order 4.00. Convergence ‖e‖ ≤ KΔx^aΔt^b (10.15):
   FTCS (2, 1). **Observed orders are meaningful only in the asymptotic range**: BTCS 1.80 on the default grids → 1.98 on
   n = 80…640; upwind 0.76 → 0.947 on n = 160…1280; Θ(¼) 0.86 → 0.995 on fine Δt.
4. **C04 Von Neumann stability.** The error obeys the same linear scheme (10.19); one Fourier mode e^{iπkx_i} is multiplied
   each step by $G=(\alpha+\beta)e^{-\mathrm i\theta}+(1-2\beta)+(\beta-\alpha)e^{\mathrm i\theta}$ (10.24), θ = kπΔx (D04);
   $|G|^2=(1-4\beta\sin^2\frac\theta2)^2+(2\alpha\sin\theta)^2$ (10.26) (D05, half-angle identities P225); with s = sin²(θ/2)
   the condition is linear in s, so testing both ends (P226) gives **Noye's lens 0 ≤ 4α² ≤ 2β ≤ 1 (10.27)** (D06, 13 steps;
   the book cites Noye without proof): β ≤ ½ ⇔ Δt ≤ Δx²/(2D) (10.28) (zigzag θ = π fails first: |G(π)| = |1 − 4β| = 1.04 at
   β = 0.51, blow-up at step 690); 4α² ≤ 2β is a *long-wave* condition; pure convection (β = 0) has |G|² = 1 + 4α² sin²θ > 1
   for every Δt. BTCS: G = 1/(1 + 4β sin²(θ/2) + 2iα sin θ), |G| ≤ 1 always (D07; β = 100 → 1/401 at θ = π).
5. **C05 Upwind, CFL, Lax.** Take the convective difference from where the flow comes from (10.29): G = 1 − C(1 − e^{−iθ}),
   |G|² = 1 − 2C(1 − C)(1 − cos θ) ⇒ stable iff 0 ≤ C ≤ 1 (10.30) (D08). The picture: **the foot of the characteristic
   x − uΔt must lie inside the stencil** (domain of dependence, P227). C = 1 is an exact shift (1e-15), not "marginal". **Slip
   R11**: for u < 0 the upwind side flips and the condition is |u|Δt/Δx ≤ 1 (`scheme="upwind_printed"` explodes, |G|max 1.5).
   With diffusion: upwind stable ⇔ |C| + 2β ≤ 1, Lax–Wendroff ⇔ C² + 2β ≤ 1. Lax equivalence (consistent + stable ⇔
   convergent, P228 well-posed): FTCS at β = 0.50 converges to the heated-rod series (10.199) at order 1.98, β = 0.51 blows up.
   Cell Péclet R_cell = uΔx/D ≤ 2 (10.31) stated here, explained in C09. Climate hook: CFL time steps 126 s (ocean, √(gH) at
   4 km depth, 25 km grid) and 78 s (atmosphere, Lamb wave ≈ 320 m/s, 25 km) — computed in the notebook.
6. **C06 Weak form.** Multiply (10.1) by w ∈ V, integrate, move the derivative of the diffusion term onto w by parts
   (P218a): $\int T_tw+u\int T_xw+D\int T_xw_x=Dq\,w(L)$ (10.36) (D09). w(0) = 0 kills the Dirichlet end; the Neumann datum
   arrives by itself (**natural**), the Dirichlet value is built into 𝒮 (**essential**). Reversing (D10, fundamental lemma
   P231) recovers the PDE and T_x(L) = q (10.37)–(10.38); the FE slope at L only *approaches* q (≈ 0.8 order on our meshes).
7. **C07 Galerkin with hats.** T^h = Σd_AN_A + gN₀, test with every N_A (arbitrary coefficients ⇒ every bracket zero, P233)
   ⇒ **M ḋ + K d = F** (10.54)–(10.58) (D11, 13 steps; K is not symmetric when u ≠ 0 — the convective part differentiates
   only the trial function). On a uniform mesh the interior row is $\frac d{dt}(\frac{T_{A-1}}6+\frac{2T_A}3+\frac{T_{A+1}}6)
   +\frac u{2h}(T_{A+1}-T_{A-1})-\frac D{h^2}(T_{A-1}-2T_A+T_{A+1})=0$ (10.63) (D12): **the centred FD stencils with a
   ⅙–⅔–⅙ averaged time derivative** — steady FE = centred FD to ≤ 1e-12.
8. **C08 Element matrices and assembly.** Map each element to ξ ∈ [−1, 1] (dx = (h/2)dξ, P234; D13 with slip R1: on
   [x_{A−1}, x_A] the local shapes are N_{A−1}, N_A); one 2 × 2 block $\mathbf m^e=\frac h6\begin{pmatrix}2&1\\1&2\end{pmatrix}$,
   $\mathbf k^e=\frac u2\begin{pmatrix}-1&1\\-1&1\end{pmatrix}+\frac Dh\begin{pmatrix}1&-1\\-1&1\end{pmatrix}$ (D14; the book
   never writes the numbers), scatter-added (`np.add.at`, P235) with A ∈ {e − 1, e} (slip R2), reproduces (10.63)·h. This is
   why FE meshes any geometry.
9. **C09 Convection-dominated layers.** Exact $T=(e^{Rx/L}-1)/(e^R-1)$, R = uL/D (10.86)–(10.87) (D15; overflow-safe
   scaled form beyond R ≈ 700), δ/L = O(1/R) (10.89), e⁻¹ = 36.79 % and e⁻² = 13.53 % one and two layer-thicknesses in. The
   centred scheme is solved **exactly** by a geometric trial (P236): $T_j=(r^j-1)/(r^n-1)$, $r=(1+R_{cell}/2)/(1-R_{cell}/2)$
   — **negative for R_cell > 2, so r^j alternates: wiggles** (D16, 12 steps; the book gives only a heat-balance argument).
   Upwind has r = 1 + R_cell > 0 but solves $uT_x=D(1+0.5R_{cell})T_{xx}$ (10.94) (D17): numerical diffusivity uΔx/2
   (slip R3: it is a *backward* difference). Stretched grids shrink the wiggles (0.35 → < 1e-4), not remove them. Climate
   hook: upwind tracer advection at 10 km, u = 0.1 m/s adds 500 m²/s — above the tens to ~100 m²/s used at that resolution.
10. **C10 Weak compressibility and MacCormack.** Let the density move a little: p = c²ρ (10.99), density error O(Ma²);
    MacCormack predicts with forward differences and corrects with backward ones and averages (10.100)–(10.102)
    (predictor–corrector P238, conservation form P237). On linear advection it **is** Lax–Wendroff: second order, local error
    −(uΔtΔx²/6)(1 − C²)T_xxx, $|G|^2=1-4C^2(1-C^2)\sin^4\frac\theta2$ ⇒ stable iff C ≤ 1 (D18 ★★★, 14 steps; U_tt = a²U_xx
    from the PDE twice is the move that removes the first-order term). Upwind pays in amplitude (Gaussian 0.745 after one
    revolution at C = 0.8), MacCormack in phase (0.978, ripples trailing the square, overshoot 1.17). NS form (10.103)–(10.109)
    with coefficients c₁–c₅, arrangements FF/BB, BB/FF … cycled; time step (10.110) semi-empirical. **Our cavity default is an
    additive rule** Δt = σ/[|u|/Δx + |v|/Δy + c√(1/Δx² + 1/Δy²) + 2ν(1/Δx² + 1/Δy²)] (DEVIATION; the inviscid bracket alone
    gave NaN at Re = 5 on 64² — review M3); at Re = 100, 64²: (10.110) 2.79e-4 vs additive 5.62e-4.
11. **C11 Splitting and projection.** Split one step into "convect and diffuse" then "add the pressure that removes the
    divergence" (10.111)–(10.118); the splitting error is ½Δt²[A₁, A₂] per step (P241) ⇒ Marchuk–Yanenko first order (0.99);
    Glowinski's Θ-scheme second order only at Θ = 1 − 1/√2 (2.00; sympy: the Δt² coefficient vanishes only there). **The
    continuous projection** (D19, ours: the book writes only the discrete (10.124)): divergence of (10.117) with ∇·u^{n+1} = 0
    ⇒ $\nabla^2p^{n+1}=\nabla\cdot\mathbf u^{n+1/2}/\Delta t$; the correction −Δt∇p is curl-free (Helmholtz–Hodge, P240), so
    projection deletes exactly the divergent part. Pressure = Lagrange multiplier of continuity (P239). Climate hook: the
    Boussinesq/anelastic pressure solve; dynamics/physics splitting in GCMs.
12. **C12 Staggered (MAC) grid.** p at cell centres, u and v on faces (the **Arakawa C-grid**): discrete divergence (10.123)
    and face gradient (10.126) are compact two-point differences; the cell budget gives the discrete Poisson equation (10.124)
    whose wall rows need **no pressure boundary condition** (the wall-face velocity is data, never corrected; slip R4: the
    book names (10.120)), singular with the constant null vector ⇒ Σ rhs = 0 and pin one value (P243) (D20; 3-cell pipe
    p − p₁ = 0, 1, 2). **Checkerboard** p = (−1)^{i+j}: collocated centred gradient (10.125) = 0 everywhere, staggered
    ±2/Δx (D21); SVD null spaces 4 vs 1 (P245). After projection max|∇·u| ≤ 1e-12. Stability (10.127)–(10.128) (cited, checked
    by a 2-D von Neumann scan and runs at 0.95×/1.05×). MAC is first order in time.
13. **C13 Mixed FE and LBB.** Weak NS (10.134)–(10.135) (D22: −∇p·ũ = −∇·(pũ) + p∇·ũ; (1/Re)∇²u = (2/Re)∇·D[u] when
    ∇·u = 0; D:∇ũ = D:D[ũ] because D is symmetric) → saddle-point system [[A, B], [Bᵀ, 0]] (10.137) (P246). With equal-order
    P1–P1 some pressure patterns are invisible to the discrete divergence (7 spurious modes at n = 2; the FE checkerboard);
    Taylor–Hood P2–P1 keeps the inf–sup constant bounded: **β_h = 0.3666, 0.3677, 0.3662 for n = 2, 4, 8**, P1–P1's first
    nonzero one falls 0.10 → 0.072 (generalised eigenproblem P247). Cylinder in a channel: P2 isoparametric triangles
    (10.184)–(10.185) (barycentric P248, Jacobian P249), 7-point degree-5 rule (10.198), Newton quadratic (residuals 0.27 →
    9.7e-17), Kovasznay orders u 3.00, p 2.23 (16 → 32), our confined Re = 100 wake St = 0.2054 (W = 5d, **qualitative**).
14. **C14 Lid-driven cavity.** MAC 64² at Re = 100: max centreline deviation from **Ghia (1982) Table I 0.26 % of U**; centre
    (0.6158, 0.7371) vs Ghia (0.6172, 0.7344) (< one cell); MacCormack (Ma 0.08, additive Δt) 4.14 %, 1.38 %, 0.44 % at
    32/64/128² (mass drift −0.68/−0.56/−0.49 %: wall-density closures are not in conservation form). **MAC 128² (0.46 %) is not
    closer to Ghia than 64² (0.26 %)**: both are at the level of Ghia's own 129² error — the comparison measures Ghia; the
    64² → 128² change is 0.204 % of U. Evidence, not proof.
15. **C15 Grid convergence and Richardson.** From e = Kh^p (10.15): p = ln[(f₃ − f₂)/(f₂ − f₁)]/ln r, f₀ ≈ f₁ + (f₁ − f₂)/(r^p − 1)
    (D23), GCI with F_s = 1.25. Cavity ψ_min on 32/64/128²: −0.101363, −0.102986, −0.103392 → **p = 2.00, f_ext −0.103528,
    GCI_fine 0.164 %**. The block-in-a-channel C_D at Re = 20 (4.272, 4.423, 4.534) gives **p = 0.43 — a failed (non-asymptotic)
    study, taught as such**; lift → 0 at order ≈ 1.1. Checklist (N111): benchmark, mesh refinement, time-step refinement,
    boundary insensitivity; verification (right equations solved right) vs validation (right equations, P253).

## 4. Mathematics → Python lessons (new pitfalls only)
- **A bug invisible to tests because the cached tables were written by the same buggy code.** `primary_vortex_centre`
  added −¼(f₂ − f₀)s* instead of +¼(f₂ − f₀)s* for the parabola vertex value, pushing the fitted ψ_min *above* the discrete
  minimum (paraboloid −0.1 → −0.09505). The tests compared live runs with CSV tables produced by the same function, so they
  agreed; the C15 order came out 1.94 instead of 2.00. Fix: **test a fitted/derived quantity against an exact analytic field**
  (a separable paraboloid: vertex and ψ_min to 1e-12/1e-14) and assert an inequality that must always hold (fitted ≤ grid
  min); regenerate every cached table after a fix and re-check its consumers (CSV headers, `explainer_tables.json`, parity rows).
- **A series must stop on its term envelope, never on the actual term.** `rod_heating_exact` (10.199) stopped when a term was
  small — which happens wherever sin((2m − 1)πx/L) = 0 — and returned −0.110 at x = 0.2, t = 0.001. Stop when
  4/((2m − 1)π)·exp(−D(2m − 1)²π²t/L²) < tol; test against an independent solution (the erfc image sum) at points where
  sines vanish and on grids with nodes at such points.
- **A default time step that silently drops a stability term gives NaN, not an error.** `cavity_maccormack` defaulted to
  the inviscid bracket of (10.110) (no viscous rate): Re = 5 on 64² and Re = 2 on 32² produced NaN within 50 steps. Every
  explicit solver now takes an explicit rule (`dt_rule="additive" | "tap"`), computes the full limit and **raises when the
  requested Δt exceeds it** (`check_stability=True`); tests cover the low-Re corner and the raise.
- **An operator built by overwriting end entries breaks on degenerate grids.** `_lap1d` assigned −1 at both ends after
  building tridiag(1, −2, 1); with one cell both assignments hit one entry (a Dirichlet ghost appeared) and a periodic
  2-cell direction lost a wrap entry. Build 1-D operators **link by link from real neighbours** (`+=`), and test the
  constant null vector on 1-cell and 2-cell grids (walls and periodic).
- **A reference evaluated in floating point can be the error.** `advect_periodic` compared an exact shift with f(x − kC/N):
  (0.2 − 1.0) % 1 = 0.19999999999999996 moved the square's edge by a node and reported rms 0.14 for a bit-exact result. Shift
  by integers when kC is whole; round the argument before an edge comparison.
- **Guard the degenerate case of every formula with a division**: GCI with |(f₃ − f₂)/(f₂ − f₁)| = 1 ⇒ p = 0 ⇒ rᵖ − 1 = 0
  raised ZeroDivisionError; now NaN with `monotone=False`.
- **Observed orders only in the asymptotic range** — state the grids with every order (BTCS 1.80 → 1.98, upwind 0.76 →
  0.947, Θ(¼) 0.86 → 0.995); a study with p far from the scheme's order (block C_D 0.43) is reported as non-asymptotic and
  qualitative, never as "grid independent".
- **Convergence to a benchmark saturates at the benchmark's own error**: MAC 128² is not closer to Ghia than 64²; use
  self-convergence (ψ_min p = 2.00) as the convergence evidence and the benchmark only as agreement within its accuracy.
- **Weak compressibility on a fixed grid gets worse as Ma falls** (TG 32²: 0.0062, 0.0099, 0.0197 for Ma = 0.1, 0.05, 0.025):
  Δt ∝ Ma·Δx, and the acoustic truncation error ∝ cΔx² accumulates; the O(Ma²) error hides behind it until the grid is fine.
- **Non-conservative boundary closures leak mass** (MacCormack cavity −0.5 %); label such solvers "not conserved" and report
  the drift with the result.
- **A required argument beats a silent default for scheme-dependent quantities**: `numerical_diffusivity("upwind")` with
  C = 0 returned the steady value; C is now required for unsteady schemes. `mac.step/run(lid=1.0)` turned every walled top
  into a lid; default `None`.
- **Reason strings are part of the API**: `stability_verdict` reason text was wrong for upwind/Lax–Wendroff with β > 0
  (true limits |C| + 2β ≤ 1, C² + 2β ≤ 1, derived in closed form by the verifier); the explainer mirroring it went stale —
  pin reason strings by exact-text parity rows.
- **Printed slips as executable counter-examples** (again, ch09 pattern): `upwind_printed` explodes to 1.4e16 for u < 0,
  `printed_step5` loses the density in 35 steps, `printed_10_172` gives a 1.7e55 Poiseuille error, `shape_slopes(printed=True)`
  fails the chain rule, `connectivity(printed=True)` fails assembly, `steady_cd_fd(scheme="forward")` wiggles for R_cell > 1.
- **Heavy runs are cached with a parameter key and invisible to mutants**: mutants in code only reached by the cached 128²
  runs are not killed by the default suite (verification Open item 6); keep one slow test that recomputes a coarse cached
  run and compares it with its table to 6 s.f.
- **Mutation testing works when solvers have iteration caps** — 38/38 killed, none hung (the ch09 hang lesson applied).

## 5. Conventions used (see `knowledge/notation.md`)
- §10.2–10.3 **dimensional** (x, L, Δx [m]; t, Δt [s]; u [m/s]; D [m²/s]; T any unit); §10.4 NS **non-dimensional** with Re
  (10.81); MacCormack NS (10.103)–(10.109) dimensional with μ and c, the cavity algorithm non-dimensional (p = ρ/Ma²,
  Re = ρ₀UL/μ); block lengths in block sides, FE cylinder in diameters d (t̄ = tU/d); force coefficients per span on ½ρU²d.
- **Three grids**: node-based FD grid x_i = iΔx (FD, MCK: ρ, ρu, ρv collocated at nodes, walls on node lines); element mesh
  (FEM1 nodes x_0 … x_n, element e = [x_{e−1}, x_e]; FEM2 vertices first then edge mid-nodes, local nodes as Fig. 10.17);
  staggered cell grid (MAC: p[j, i] at ((i + ½)Δx, (j + ½)Δy), u[j, i] at x = iΔx, v[j, i] at y = jΔy; the book's
  u_{i+1/2, j} ↔ `u[j, i+1]`). Layout `[j, i]` = (y, x) as in ch02.
- **Fourier convention**: the book's e^{iπkx_i}, θ = kπΔx (k counts half-waves per unit length); code takes θ directly and
  offers `fourier_mode(convention="standard")` (e^{ikx}, θ = kΔx).
- **i** is both the grid index and √−1 in (10.20)–(10.24): upright $\mathrm i$ for √−1, grid index j in our own lines.
- **α, β, θ overloaded**: FTCS α = uΔt/(2Δx), β = DΔt/Δx²; **Courant C = 2α**; Glowinski's Θ-scheme weights α_Θ, β_Θ and
  fraction Θ; FE time weights α_t, β_t ((10.163): backward Euler (1, 0), trapezoidal (2, 1)); θ = Fourier angle; Ch. 8's
  θ-method (θ = 0, ½, 1) in `FEM1.solve_transport(theta=)` and `crank_nicolson_1d`.
- **Ma** for the Mach number everywhere (the book writes M in (10.151)–(10.155)); **M** bold = FE mass matrix; **K** bold =
  stiffness, K_e = error constant of (10.15); **𝒮** trial space vs **St** Strouhal (cyclic frequency, as ch09); **R** global
  Péclet uL/D vs **R_cell** = uΔx/D; **δ** layer thickness vs Kronecker δ_AB (always two indices); **F** FE load vector vs
  y-flux of the conservation form; **G** amplification factor vs G_A weak-form residual row; **p** pressure vs "order p";
  **D** diffusivity vs **D**[u] strain rate (bold, brackets; write 2**D**[u]); **g** Dirichlet value vs body force (g_x, g_y);
  **n** time level (superscript), cells/elements, n_el in element loads, shedding frequency f_s; **λ** in ch10 = eigenvalue
  (generalised eigenproblem β_h² = λ_min, split system eigenvalues, y′ = λy test).
- **Printed slips are named "slip #1 … #12" in the notebook** (the analysis and code call them R1 … R12) so they cannot be
  confused with recap IDs R01 … R13.
- **Our own run parameters** (book ones are private): cavity Ma 0.08 (MacCormack), block Ma 0.06, channel H = 4 (8 ahead,
  20 behind), FE cylinder channel W = 5d, safety σ = 0.8.
- **Changes vs earlier chapters**: θ is a Fourier angle (ch09 momentum thickness, angle elsewhere); λ an eigenvalue (ch09
  Thwaites parameter); p′ = Newton correction (ch04/ch07 perturbation pressure); δ = convection–diffusion layer thickness
  (ch09 similarity length); R = Péclet number (ch08/ch09 radius); G = amplification factor (ch01 Gibbs, ch02 velocity-gradient
  tensor G); D = diffusivity (ch01 mass diffusivity κ-like; ch04 D/Dt); C = Courant number (ch09 constants); S = trial space;
  M = mass matrix (ch01 molecular mass M_w).
