# Chapter 10 reference data — sources

Public, cited benchmark tables are produced by `reference/ch10/make_refs.py`; the other CSV files in this folder are **our own
computed results** (cached heavy runs written by `scripts/ch10_*.py`, regenerated by re-running the script named in each file's
header line). Book-quoted numbers are **not** here (they live in the git-ignored `tests/book_values_ch10.json`).
